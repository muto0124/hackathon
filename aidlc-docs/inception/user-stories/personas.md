# Personas

## Primary Persona: 佐藤 悠真

| Item | Description |
| --- | --- |
| 属性 | 32 歳、一人暮らしのビジネスパーソン |
| 状況 | 平日は仕事で多くの判断を行い、退勤後は食事、服装、買い物、予定を考える余力が少ない。 |
| 課題 | 選択肢が多すぎるほど動けなくなり、結局いつも同じ食事や先延ばしに流れる。 |
| T-AI-DA に期待すること | 比較ではなく一択の判断を受け取り、生活の小さな選択から解放されること。 |
| 成功条件 | 朝にその日の生活方針が決まり、迷った瞬間も即決ボタンで止まらず行動できる。 |

## Secondary Persona: 田中 美咲

| Item | Description |
| --- | --- |
| 属性 | 25 歳、社会人 3 年目、一人暮らし |
| 状況 | 生活管理が苦手で、献立、買い物、休日の過ごし方を毎回考えるのが面倒。 |
| 課題 | 自分の好みや予算に合う選択肢を探すうちに疲れ、生活の質が安定しない。 |
| T-AI-DA に期待すること | 天気、予定、好み、予算を踏まえて、低リスクな生活判断をまとめて決めてほしい。 |
| 成功条件 | 自分で調べる時間が減り、日常の準備が具体的な行動に変わる。 |

## Future Persona: 鈴木 健

| Item | Description |
| --- | --- |
| 属性 | 38 歳、選択肢過多に疲れた消費者 |
| 状況 | サブスク、買い物、旅行、趣味、学習などの比較に時間を使いすぎている。 |
| 課題 | レビューやランキングを見ても決めきれず、意思決定そのものを外部化したい。 |
| T-AI-DA に期待すること | 将来的には消費やライフスタイル選択も、制限付きで任せられること。 |
| 成功条件 | T-AI-DA が安全境界を守りながら、低リスクな選択を先回りして準備する。 |

## Persona Fit

初期 MVP は Primary Persona を中心に設計する。Secondary Persona は生活管理ユースケースの補助視点として扱う。Future Persona は将来拡張の方向性を示すが、MVP スコープには含めすぎない。
